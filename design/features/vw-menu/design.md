# VW MENU surface

Status: approved — user supplied direction and requested implementation without a planning stop.

Centered public interface, persistent sidebar, scrollable aligned rows, search, reusable controls, short hover/selection feedback, native color fields and profile selector. Requested state is distinct from effective module/server state. Open initially; both CTRL keys toggle with latch; typing/rebinding suppress shortcuts. Empty/unsupported/error/locked states remain readable in Diagnostics and preserve UI. Constrain scale and drag to viewport; compact scaled layout for small screens and scroll all long pages. Notifications and tooltips never cover navigation. No key/whitelist to show interface.

Visual engine verification pending: no Studio connected. Local boundary tests cannot prove pixel layout or touch usability.
